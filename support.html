Support

How can we help?

Questions, bug reports and feature requests are welcome.

Contact

Open an issue on GitHub: github.com/kafka-glass/desktop-app/issues. Please include your macOS version, the app version (KafkaGlass Explorer › About), your Kafka distribution and version, the security protocol you use and the exact error message.

Never paste passwords, private keys or production message payloads into an issue—issues are public.

Common questions

The app can’t connect to my cluster.

Check that the bootstrap servers are reachable from your Mac (VPN, firewall, advertised listeners) and that the security protocol matches the listener you’re connecting to. The topic’s Logs tab shows the broker activity log with connection errors from librdkafka.

My certificate file is “not readable”.

KafkaGlass runs in the macOS App Sandbox, so it can only read files you select with the file picker. Open Cluster › Edit Cluster Settings… and choose the CA, client certificate and key files again with the Browse… button rather than typing their paths.

SSL fails with a certificate verification error.

If your brokers use a private CA, select its certificate as the CA file in the cluster settings. Without one, KafkaGlass verifies the brokers against the system root certificates.

Avro messages show up as hex.

Enable Schema Registry in the cluster settings and check its URL and credentials. Avro decoding applies to messages in the Confluent wire format (magic byte 0x00 followed by a 4-byte schema ID).

Does fetching messages affect my consumers?

No. KafkaGlass reads with manual partition assignment and never joins a consumer group or commits offsets.

How do I get a refund?

App Store purchases are handled by Apple. Request a refund at reportaproblem.apple.com.
