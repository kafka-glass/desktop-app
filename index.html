Features

Everything you reach for when Kafka misbehaves

A native SwiftUI client built on librdkafka. It opens instantly, stays light on memory and talks to your brokers directly—no JVM, no Docker container, no browser tab.

All your clusters

Save profiles for local, DEV, QA and PROD clusters and switch between them from the sidebar in a click.

Fetch exactly what you need

Tail the newest records, read from the earliest, jump to an offset or to a point in time—per topic or per partition—then filter by key instantly.

Avro, JSON, XML & hex

Auto-detect decodes Confluent Avro with schemas from your Schema Registry, pretty-prints JSON and XML, and falls back to text or a canonical hex dump.

Produce & resend

Publish a record with key, value and headers as text, JSON, hex, Base64 or a null tombstone—or right-click any fetched message to resend it.

Live statistics

Throughput per topic and partition, consumer group lag and broker round-trip times, streamed from librdkafka and charted over the last minute.

Enterprise security

Mutual TLS, SASL PLAIN, SCRAM-SHA-256/512 and Kerberos, with every secret kept in the macOS Keychain—never in a config file.

Message Inspector

See what’s really inside every record

Select a message and KafkaGlass figures out the format for you. Confluent wire-format payloads are decoded with the exact schema version they were written with.

  • Schema Registry aware. Reads the magic byte and schema ID, fetches the schema once and caches it for the rest of the session.
  • Every view you need. Switch between Avro, JSON, XML, plain text and a hex dump with byte offsets and ASCII columns.
  • Copy anything. Selectable payloads, one-click key copy and full record headers right next to the value.

Produce

Send a test message in seconds

Press ⇧⌘P to open the Produce sheet on the current topic. KafkaGlass waits for the brokers to acknowledge the write and tells you exactly where it landed.

  • Key, value and headers. Encode as text, validated JSON, hex, Base64, a fresh UUID key or a null tombstone for compacted topics.
  • Pick the partition. Let Kafka hash the key or pin the record to a specific partition.
  • Resend in one click. Right-click a fetched record to reopen it prefilled with its partition, key, value and headers.

Statistics

Watch the cluster breathe in real time

The Statistics workspace streams librdkafka metrics into live charts, so you can spot a stuck consumer or a slow broker before anyone files a ticket.

  • Throughput. Messages and bytes per second for the whole cluster, each topic and each partition.
  • Consumer group lag. Committed offsets versus the log end, group state and members at a glance.
  • Broker health. Average, p95 and p99 round-trip times, throttling and reconnects per broker—plus Pause when you’re done.

Schema Registry

Browse subjects and diff schema versions

Connect a Confluent-compatible Schema Registry and get a searchable list of subjects, their latest versions and IDs, and the full schema text.

  • Search by name or ID. Paste the schema ID from the message inspector to jump straight to its subject.
  • Version diff. Compare any two versions line by line to see which field was added, removed or retyped.
  • Topic tools included. Create topics, inspect partitions, leaders, replicas and ISR, and review every topic config.

Security & Privacy

Safe to point at production

KafkaGlass talks only to the brokers and Schema Registry you configure. No accounts, no analytics, no cloud relay in between.

Read without side effects

Messages are fetched with manual partition assignment—no consumer group is joined and no offsets are committed.

Secrets in the Keychain

SASL passwords, key passphrases and registry credentials live in the macOS Keychain, never in plain text.

App Sandbox

The app reads only the certificate files you pick yourself, through security-scoped bookmarks.

Zero telemetry

No analytics, crash reporters or tracking. Your topics and payloads never leave your Mac and your cluster.

FAQ

Questions, answered

Does browsing a topic commit consumer offsets?

No. KafkaGlass Explorer reads messages with manual partition assignment and no consumer group subscription, so fetching never commits offsets or joins your application’s consumer groups.

Do I need to install librdkafka or Homebrew?

No. librdkafka, OpenSSL, lz4 and zstd are bundled inside the app. Download it, connect to a cluster and start browsing.

Which security protocols are supported?

PLAINTEXT, SSL with mutual TLS client certificates and CA verification, and SASL_PLAINTEXT / SASL_SSL with PLAIN, SCRAM-SHA-256, SCRAM-SHA-512 and GSSAPI (Kerberos).

Where are my passwords stored?

SASL passwords, private key passphrases and Schema Registry secrets are stored in the macOS Keychain. Cluster profiles themselves are kept locally on your Mac.

Can it decode Avro messages?

Yes. Messages in the Confluent wire format (magic byte 0x00 + schema ID) are decoded with schemas fetched from your Schema Registry. JSON, XML, plain text and hex views are always available.

Can I delete or purge topics?

Yes, with a confirmation step. Internal topics such as __consumer_offsets and _schemas are always protected from deletion and purging.

What are the system requirements?

macOS 27.0 or later on a Mac with Apple Silicon.
